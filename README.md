# SweetchBAIR
Версия Sweetch с доработками Алексея для Windows 10/11 x64.
## Скачать
[Последняя версия программы](https://github.com/21monstarvgta-netizen/SweetchBAIR/releases/latest)
Распакуйте весь ZIP и запустите Sweetch.exe. Python и .NET входят в комплект.
Начиная с 1.0.5 программа предлагает обновления из GitHub Releases. Более старые версии нужно обновить вручную один раз.
В каждом выпуске приложены полный архив программы, SHA-256 и Sweetch-source.zip с исходниками соответствующей версии и уведомлениями о лицензиях.
Основано на [krllmrzv/Sweetch](https://github.com/krllmrzv/Sweetch). Лицензии и авторские уведомления сохранены в поставке.
